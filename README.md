# AIQuotaRelay

AIQuotaRelay 是一款 Windows 任务栏 AI 额度监控工具，可集中显示额度、余额、重置时间、Token 与本地成本历史。

本仓库用于托管 AIQuotaRelay 产品官网和公开下载页面。

## 官网

https://lanzier.github.io/AIQuotaRelay/

## 隐私

应用在本机读取受支持 AI 工具已有的本地会话或凭据，并直接向相应服务商查询额度。AIQuotaRelay 不运营中转服务器，也不收集遥测。官网不包含分析、广告或第三方跟踪。
